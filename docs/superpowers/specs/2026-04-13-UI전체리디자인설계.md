# UI 전체 리디자인 설계

> 작성일: 2026-04-13
> 참고: `asset/figma/Data Table v2 (Community).fig`

---

## 목표

Figma "Data Table v2 (Community)" 디자인을 참고하여 전체 UI를 통일감 있게 개선한다.
- 퍼플-그레이 배경 팔레트 + Freesentation 폰트 적용
- ListPage 레이아웃을 사이드바 → 상단 필터탭+검색바 구조로 전환
- 정렬, 페이지네이션, 검색 기능 추가
- 모든 페이지(Login, List, Review)와 공통 컴포넌트 통일

---

## 디자인 토큰

### 색상 팔레트 (`tailwind.config.js` 확장)

| 토큰 | 값 | 용도 |
|------|----|------|
| `surface` | `#f1f0f6` | 전체 페이지 배경 |
| `card` | `#ffffff` | 카드/테이블 배경 |
| `stroke` | `#e5e4ef` | 구분선, 입력 테두리 |
| `primary.DEFAULT` | `#6c63ff` | 포인트 컬러 (버튼, 포커스 링, 선택 상태) |
| `primary.hover` | `#574fd6` | hover 상태 |
| `primary.light` | `#ededf8` | 행 hover 배경, 선택 배경 |
| `ink.strong` | `#1a1825` | 주요 텍스트 |
| `ink.base` | `#4b4860` | 일반 텍스트 |
| `ink.muted` | `#9693a8` | 보조/플레이스홀더 |

### 상태 색상

| 상태 | bg | text |
|------|----|------|
| `pending` (검수전) | `#fff4e6` | `#c17d11` |
| `reviewing` (검수중) | `#e8f0fe` | `#2956b2` |
| `reviewed` (검수완료) | `#e6f4ea` | `#1e7e34` |

### 폰트 (`index.css` + `tailwind.config.js`)

`asset/font/` 폴더의 Freesentation 폰트를 `@font-face`로 등록한다.

```css
/* index.css */
@font-face {
  font-family: 'Freesentation';
  src: url('/fonts/Freesentation-4Regular.ttf') format('truetype');
  font-weight: 400;
}
@font-face {
  font-family: 'Freesentation';
  src: url('/fonts/Freesentation-6SemiBold.ttf') format('truetype');
  font-weight: 600;
}
@font-face {
  font-family: 'Freesentation';
  src: url('/fonts/Freesentation-7Bold.ttf') format('truetype');
  font-weight: 700;
}
```

`tailwind.config.js`에서 `fontFamily.sans: ['Freesentation', 'sans-serif']` 설정.

폰트 파일은 `asset/font/`에서 `web/public/fonts/`로 복사한다.

## 페이지별 상세 설계

### 1. LoginPage

**레이아웃:**
- 전체 배경: `surface`
- 중앙 카드: `card` 배경, `rounded-2xl`, `shadow-md`, 고정 너비 `w-96`
- 카드 상단: 앱 로고 영역 (텍스트 "PII 검수", `font-bold text-2xl text-primary`)

**컴포넌트:**
- 입력 필드: `border-stroke` 테두리, focus 시 `ring-primary`
- 로그인 버튼: `bg-primary hover:bg-primary-hover text-white`, 전체 너비
- 에러 메시지: `text-red-500 text-sm` (기존 유지)

---

### 2. ListPage

**전체 구조 변경:**
- 기존 좌측 사이드바 제거
- `surface` 배경 위에 `max-w-5xl` 컨테이너

**상단 헤더 바:**
```
┌──────────────────────────────────────────────────────────┐
│  검수 목록          전체 N건  ● 검수전 N  ✓ 완료 N        │
│                                        [업로드] [Export]  │
└──────────────────────────────────────────────────────────┘
```
- 타이틀: `font-bold text-xl text-ink-strong`
- 요약 카운터: `text-sm text-ink-muted`, 상태별 색상 점(●)
- admin 전용 버튼 (업로드, Export): `border-stroke` 아웃라인 스타일

**필터 탭 + 검색 바:**
```
┌────────────────────────────────────────────────────────┐
│  [전체] [검수전] [검수중] [검수완료]    [🔍 파일명 검색] │
└────────────────────────────────────────────────────────┘
```
- 탭: 선택 시 `bg-primary text-white rounded-full px-3 py-1`
- 미선택: `text-ink-base hover:bg-primary-light rounded-full`
- 검색 입력: `source_filename` 포함 여부로 클라이언트 필터링, 우측 정렬

**테이블:**
- 컨테이너: `card` 배경, `rounded-xl`, `border border-stroke`, `shadow-sm`
- 행 hover: `bg-primary-light` (`#ededf8`)
- 열 헤더 클릭 정렬 (파일명 / 상태 / PII 수 / 검수일): 정렬 방향 표시 (`↑` `↓`)
- 컬럼 구성: 파일명, 소스, 상태, PII, 검수일, 액션(→)
- StatusBadge: 새 토큰 색상 적용

**페이지네이션:**
- 클라이언트 사이드, 페이지당 20행
- 하단 우측: `이전 / 1 / 2 / ... / 다음` 버튼
- 현재 페이지: `bg-primary text-white rounded-md`

---

### 3. ReviewPage

**배경:** `surface` 적용 (현재 `bg-white` → `bg-surface`)

**헤더:**
- `card` 배경, `border-b border-stroke`, `shadow-sm`
- 복잡도 선택 버튼: 선택 시 `bg-primary text-white`, 미선택 `border-stroke hover:border-primary`
- 저장 버튼: `bg-primary hover:bg-primary-hover`
- "검수중으로 변경" 버튼: `border-primary text-primary hover:bg-primary-light`

**좌우 패널:**
- 각 패널 내부: `card` 배경, `rounded-xl`, `border border-stroke` 카드 스타일 유지
- 섹션 레이블: `text-ink-muted` (현재 `text-gray-400` 동일 효과)

## 컴포넌트 상세 설계

### StatusBadge

현재: `bg-orange-100 text-orange-600` 등 하드코딩
변경: 상태 색상 토큰으로 교체

```jsx
const styles = {
  pending:   'bg-[#fff4e6] text-[#c17d11]',
  reviewing: 'bg-[#e8f0fe] text-[#2956b2]',
  reviewed:  'bg-[#e6f4ea] text-[#1e7e34]',
}
```

### PiiChip

- 배경: `bg-primary-light` (`#ededf8`) + hover `bg-[#dddaef]`
- 텍스트: `text-ink-strong`
- 삭제 버튼 hover: `text-red-500` (유지)
- 라운딩: `rounded-lg` (현재 `rounded-md` → 약간 더 둥글게)

### PiiEditor 카테고리 카드

각 카테고리 카드에 좌측 컬러 보더 추가:

```jsx
// 카테고리별 좌측 보더 색상 (4px)
const BORDER_COLORS = {
  NAME:      'border-l-yellow-400',
  ADDRESS:   'border-l-blue-400',
  POSTAL:    'border-l-purple-400',
  RESIDENT:  'border-l-red-400',
  CONTACT:   'border-l-green-400',
  EMAIL:     'border-l-pink-400',
  BIRTHDATE: 'border-l-orange-400',
  GENDER:    'border-l-teal-400',
  AGE:       'border-l-indigo-400',
}
// 카드: `border border-stroke border-l-4 ${BORDER_COLORS[category]} rounded-xl`
```

### TextViewer

- 배경: `bg-surface` (현재 `bg-gray-50`)
- 검색 바: `border-stroke` 테두리, `ring-primary` 포커스
- 툴바 배경: `card`
